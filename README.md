# WonderIsland

WonderIsland adalah fork pribadi dari Oyenza Studio v0.2.19 untuk Windows, dirombak menjadi bertema Alice in Wonderland dengan palet dominan Alice Blue (`#F0F8FF`).

## Tujuan Fork
- **Tema Tunggal:** Tema eksklusif Wonderland (Alice Blue ground, ink biru malam, aksen emas jam saku).
- **Mandiri & Privat:** Menonaktifkan pengecekan pembaruan otomatis ke upstream dan layanan eksternal Oyenza.
- **Tetap Ringan:** Menjaga prinsip dasar — tanpa timer atau thread tak perlu saat idle.
